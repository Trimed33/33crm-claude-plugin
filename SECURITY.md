# Security

Report suspected vulnerabilities privately through [33CRM support](https://crm.trimed33.com/support). Do not include passwords, tokens, verification codes, customer data or other sensitive material in public issues. Use synthetic records for reproduction.

The bundle connects only to the declared remote 33CRM MCP endpoint using user-authorized OAuth. The service is responsible for tenant isolation, authorization, data eligibility and operation-bound approval. Never bypass a refusal, send authentication secrets through Claude, or claim that skill instructions alone prevent disclosure. Ineligible workflows must stay in first-party 33CRM.
